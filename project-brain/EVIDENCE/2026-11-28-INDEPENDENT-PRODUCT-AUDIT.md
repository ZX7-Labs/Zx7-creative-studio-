## Founder intent

A solo creator should give a natural-language brief and direct or share one real creative workspace. The Brain independently chooses creative direction, work method, tools, assets, timing and revisions. It operates actual clips, layers, masks, curves, editable 3D objects and sound. The creator can manually alter the same project and the Brain can pick up from the new state. Advertising is one workload within graphics, animation, video, CGI/VFX, color, sound, original generation and delivery. Originality, production strength, usability and independently assessed value guide tradeoffs. Model replacement and local-first operation preserve founder control. Native documents, permissions, original media, revisions and verification remain host-owned. See the [preserved master plan](../../docs/ZX7_CREATIVE_STUDIO_MASTER_PLAN.md) and [founder brief](../BRIEF.md).

## Architecture judgment and first decision

Retain replaceable Brain, trusted BODY and source-owning native engines. Use one shared identity for project, native document/revision, assets and ownership references. Velorn projects, .blend files, graphics graphs, audio stems and original media keep native semantics. Reuse the current gateway, revision authority, custody and media verification. Promote additional Creative State Fabric abstractions only if matched granular-native, compositional and hybrid comparisons show gains in creative quality, cost, efficiency or edit fidelity. G2 remains unrun.

**First decision: repair the feedback and control seam around intended native actions.** The Brain chooses which sound, where it belongs and which creative effect it should achieve. The host can resolve authorized live object references, enforce the actual revision and expose deterministic preconditions. A failed verification should expose a typed, trustworthy explanation tied to current state, such as a missing audio stream when technically established. If the same file/revision/failure could add no information, direct the Brain to a fresh observation or explicit stop. Preserve model authority over the creative correction, pre-dispatch authority checks, truthful read/write receipts, human changes, explicit save, no uncertain-write replay, and all acceptance criteria. The existing G1 failure is the baseline for measuring whether this earns its complexity.
