# ZX7 Creative Studio — enduring founder brief

Status: ACTIVE engineering mandate, updated 2026-11-10 following the founder's NVIDIA-first development pivot. This is a **product brief**, not a completion announcement.

## Product and non-negotiable bar

Build one world-class **ZX7 BODY / Creative Studio**: a multidisciplinary, expressive, original creative production environment operated by an AI **Brain** that independently researches, chooses artistic direction, creates, observes, critiques, revises and delivers **real editable native projects**. Video, motion/2D, graphics, typography, CGI/3D/VFX, photography, color, sound and adjacent studio functions remain in scope. The exact comprehensive A–L contract and acceptance conditions are in [CAPABILITIES.md](../CAPABILITIES.md).

Beat relevant professional workflows on *independently measured work*, not on a model's apparent confidence or test count. The bar includes creative originality, native editing depth, exact clocks/color/audio, provenance, privacy, licensing, security, speed, cost efficiency, editability, failure recovery, human usability and sustained quality. No hard-coded storyboard, scene-count, style or fake render is acceptable.

Maintain one coherent native workspace and host-granted capability boundary; use mature source-attested open-source engines rather than rebuilding professional primitives without evidence. The model is replaceable; neither NVIDIA nor a future local model owns native permissions, source data, actions or verification.

## Current development strategy (owner delta)

**Latest owner clarification · 2026-11-13 · supersedes the timing of the earlier NVIDIA-first development instruction:** Continue building the complete Master Plan and do not invoke the NVIDIA API during the current offline/native engineering stages. Use it **only when the system and creative evaluation path are actually ready and its use is warranted**; keep separate purpose-specific paid inference, raw-audio and private-media consent requirements. All CI must remain no-provider by default. The earlier NVIDIA-first guidance below remains the preferred candidate for a *future authorized* capable-model trial, **not permission to spend now**. Do not misrepresent scripted tests as neural creative completion.


- **NOW:** Develop and evaluate the complete AI-to-BODY workflow with the already connected **NVIDIA API** and a verified provider-capable model. Do **not** spend time on repeat, weak/local-CPU whole-workflow model evaluations. Use offline protocol, security and physical native tests wherever possible; cloud model runs should be rare, bounded, consented and supported by prior failure analysis.
- **LATER:** Evaluate local models when practical hardware and meaningful model competency tests are available. The product's intended **local-first, open-source/self-hostable and provider-agnostic** character remains a release objective. NVIDIA-assisted engineering is not a license to make paid NVIDIA inference a hidden product dependency.
- A passed hosted-model editor/permission test can establish shared BODY behavior; it **cannot** certify an untested local model's planning, reasoning, tool calling or visual creativity.

First accepted native platform: Ubuntu 24.04 x86-64; mobile/remote and full A–L remain planned, not discarded. The immediate vertical is video/NLE (C) including A/B/F/G/I/J dependencies. Multilingual, worldwide, high-quality public creative research without required API keys remains a product requirement; current built-in Wikipedia reach alone does not satisfy global full-web research.

## Hard acceptance gates

1. Genuine model independently chooses nontrivial original work from a natural-language brief without engineer-written creative action scripts; actual typed native tools and original-rights media are used.
2. Save and reopen an editable native project, independently verify and decode a brief-compliant physical first export, observe meaningful picture **and timed/audio** evidence, choose an intentional editable revision, verify a distinct conforming second output and preserve revisions/custody.
3. Verify failure cases, permission isolation, no uncertain-write replay, source identity, licensing, portability and resource ceilings. A scripted fixture is a protocol test, not neural artistic acceptance.
4. Independently review professional creative quality on diverse briefs and compare with relevant existing editor workflows. A non-empty MP4, still frame or passing test suite alone does not close an A–L domain.
5. Preserve explicit consent boundaries for private inputs, production deployment, destructive changes and paid/nontrivial API usage. Do not leak existing NVIDIA credentials into public CI artifacts, logs or the creative editor.

Owner delegated routine architecture, repository changes, tests and normal integration. A reviewed, synthetic-only, single NVIDIA trial was specifically authorized and started; further runs are not implicitly authorized without their own bounded justification.
